02 — SQL ANALYSIS

โจทย์ SQL 5 ข้อ พร้อมคำตอบ

คำตอบด้านล่างคำนวณจากข้อมูลจริงในตารางด้านบนผ่าน JavaScript (ตรรกะเทียบเท่าคำสั่ง SQL ที่แสดงไว้) — ถ้าต่อฐานข้อมูลจริง คำสั่งเหล่านี้รันตรงกับ Postgres ของ Supabase ได้เลย

1
ผลรวมของ claim_amount ในเดือนมกราคม 2026
SELECT SUM(claim_amount) AS total_claims
FROM claims
WHERE tx_date BETWEEN '2026-01-01' AND '2026-01-31';
ผลลัพธ์
2
จัดอันดับ plan_name ยอดฮิต 3 อันดับแรกตามยอดรวม claim_amount
SELECT pt.plan_name, SUM(c.claim_amount) AS total_amount
FROM claims c
JOIN plan_types pt ON c.plan_type_id = pt.plan_type_id
GROUP BY pt.plan_name
ORDER BY total_amount DESC
LIMIT 3;
ผลลัพธ์
3
นับจำนวน policyholders แยกตาม location_zone เรียงจากมากไปน้อย
SELECT location_zone, COUNT(*) AS total_policyholders
FROM policyholders
GROUP BY location_zone
ORDER BY total_policyholders DESC;
ผลลัพธ์
4
ค่าเฉลี่ยของ claim_amount สำหรับกลุ่มอายุ 18–25 ปี
SELECT AVG(c.claim_amount) AS avg_claim
FROM claims c
JOIN policyholders p ON c.policyholder_id = p.policyholder_id
WHERE p.age BETWEEN 18 AND 25;
ผลลัพธ์
5
policyholders ที่มีผลรวม claim_amount มากกว่า 10,000 (กลุ่ม High-value / High-risk)
SELECT p.policyholder_id, p.name, SUM(c.claim_amount) AS total_claim
FROM claims c
JOIN policyholders p ON c.policyholder_id = p.policyholder_id
GROUP BY p.policyholder_id, p.name
HAVING SUM(c.claim_amount) > 10000
ORDER BY total_claim DESC;
ผลลัพธ์
