QUERY WORKBOOK

SQL Answers

คำตอบ SQL ทั้ง 5 ข้อ พร้อมผลลัพธ์จากชุดข้อมูลตัวอย่าง

01 / ยอดเคลมเดือนมกราคม
SELECT SUM(claim_amount) AS total_claims
FROM claims
WHERE tx_date BETWEEN '2026-01-01' AND '2026-01-31';
RESULT฿ 33,200
02 / 3 แผนยอดเคลมสูงสุด
SELECT p.plan_name, SUM(c.claim_amount) AS total_claims
FROM claims c JOIN plan_types p ON c.plan_type_id = p.plan_type_id
GROUP BY p.plan_name ORDER BY total_claims DESC LIMIT 3;
RESULTFamily Care · ฿12,500
03 / จำนวนผู้ถือกรมธรรม์ตามโซน
SELECT location_zone, COUNT(*) AS policyholder_count
FROM policyholders GROUP BY location_zone ORDER BY policyholder_count DESC;
RESULTกรุงเทพฯ · 2 ราย
04 / ค่าเฉลี่ยเคลมกลุ่มอายุ 18–25
SELECT AVG(c.claim_amount) AS avg_claim
FROM claims c JOIN policyholders p ON c.policyholder_id = p.policyholder_id
WHERE p.age BETWEEN 18 AND 25;
RESULT฿ 8,350
05 / กลุ่ม High-value / High-risk
SELECT p.name, SUM(c.claim_amount) AS total_claims
FROM policyholders p JOIN claims c ON p.policyholder_id = c.policyholder_id
GROUP BY p.name HAVING SUM(c.claim_amount) > 10000;
RESULTสุภาวดี แสงทอง · ฿12,500
